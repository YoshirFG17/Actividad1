# Proyecto HTML: Uso de Imágenes, Videos y Estructura

## Descripción
En esta actividad se creó una página web básica usando HTML. Se aplicaron etiquetas principales para organizar el contenido y se añadieron imágenes y videos.

---

## Estructura utilizada

### Encabezados
Se usaron:
- h1 para el título principal
- h2 para subtítulos

### Separadores
- hr para dividir secciones

---

## Contenido multimedia

### Imágenes
Se utilizó la etiqueta:
<img src="imagen.jpg" alt="Descripción">

### Videos
Se utilizó:
<video controls>
  <source src="video.mp4" type="video/mp4">
</video>

---

## Listas

### Lista ordenada
<ol>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ol>

### Lista desordenada
<ul>
  <li>Elemento A</li>
  <li>Elemento B</li>
</ul>

---

## Objetivo
- Aprender la estructura básica de HTML  
- Usar etiquetas como h1, h2 y hr  
- Insertar imágenes y videos  
- Crear listas ordenadas y desordenadas  

---

## Resultado
Se logró una página web simple, organizada y funcional.

---
